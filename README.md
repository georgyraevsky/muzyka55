# Георгий Раевский — музыкальное шоу на праздник

Премиальный лендинг для заказа живого музыкального шоу (аккордеон + вокал) в Омске:
свадьбы, юбилеи, корпоративы, велкомы в ресторанах.

Сайт статический: один HTML-файл, готовый CSS, немного ванильного JS. Ни одной внешней
зависимости в рантайме — при загрузке страницы не происходит ни одного запроса на чужие домены
(шрифты и стили лежат локально).

---

## Структура проекта

```
muzyka55/
├── index.html              ← весь сайт (разметка + контент)
├── robots.txt
├── sitemap.xml
├── .nojekyll               ← нужен, чтобы GitHub Pages не трогал файлы через Jekyll
└── assets/
    ├── css/
    │   ├── input.css       ← ИСХОДНИК стилей (правим только его)
    │   └── main.css        ← СОБРАННЫЙ файл (вручную не править!)
    ├── js/
    │   └── main.js         ← вся интерактивность
    ├── fonts/              ← 24 файла woff2 + fonts.css
    └── images/             ← фотографии, иконка, обложка для соцсетей
```

Служебные папки (`tools/`, `shots/`, `RECON/`, `node_modules/`) на сайт не влияют —
их можно не выкладывать. `RECON/` хранит архив исходного сайта на Tilda.

## Как обновить контент

Почти всё меняется прямо в `index.html`:

| Что менять | Где искать |
|---|---|
| Заголовок первого экрана | `<h1>` внутри `<section id="top">` |
| Тексты преимуществ | `<section id="why">`, карточки `<article class="bezel ...">` |
| Программы | `<section id="programs">`, пять `<article>` |
| Кейсы | `<section id="cases">` |
| Телефон, WhatsApp, VK | поиск по `79333338242` и `vk.com/georgy_raevsky` |
| Цифры (10 лет, Омск) | `<dl>` в первом экране |

**Важно:** тексты внутри блоков с классом `reveal` анимируются при скролле —
это не ошибка, если в редакторе они выглядят «полупрозрачными».

## Как поправить стили

Стили написаны на Tailwind CSS v4, но **сборка нужна только если вы меняете `input.css`
или добавляете новые CSS-классы в HTML**. Если правите только текст — ничего собирать не надо,
`main.css` уже готов.

```powershell
npm install          # один раз
npm run css          # пересобрать assets/css/main.css
npm run css:watch    # пересобирать на лету, пока работаете
```

Что внутри `input.css`:

- `@theme` — палитра и шрифты. Тёмная база `noir #0b0908`, кремовый текст, одна латунная
  акцентная краска `brass #c7a26a`.
- `.bezel` + `.bezel-core` — двухслойная «обойма» карточек: снаружи тонкая светящаяся рамка,
  внутри плотная подложка. Ей обёрнуты все 15 карточек сайта.
- `.reveal` / `.reveal-scale` — появление блоков при скролле: подъём, проявление и снятие
  размытия.
- `.spot` — тёплый блик, который следует за курсором по карточкам.
- `.bar-1` / `.bar-2` — две линии гамбургера, которые складываются в крестик.
- `.menu-link` — ссылки полноэкранного меню; задержка каждой считается от её номера
  (`--i`), поэтому они встают лесенкой.
- `prefers-reduced-motion` — если у человека в системе включено «уменьшить движение»,
  все анимации отключаются.

## Локальный просмотр

```powershell
npm run serve        # http://127.0.0.1:4173
```

Открывать `index.html` двойным кликом тоже можно, но тогда часть шрифтов может не загрузиться
из-за ограничений `file://` — сервер надёжнее.

## Публикация на GitHub Pages

1. Создайте репозиторий и залейте туда всё, кроме `node_modules/`, `shots/`, `tools/`.
   `assets/`, `index.html`, `.nojekyll` — обязательно.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.

Все пути в проекте **относительные** (`assets/...`, `#contacts`), поэтому сайт работает
и в корне домена, и в подпапке — ничего переписывать не нужно.

**Перед публикацией на своём домене** замените `https://accordion55.ru/` на реальный адрес
в трёх местах: `<link rel="canonical">`, `og:url`/`og:image`, `robots.txt` и `sitemap.xml`.
Соцсети читают `og:image` только по абсолютной ссылке — поэтому там полный адрес.

## Что проверено

- Консоль браузера чистая, ошибок и упавших запросов нет.
- Горизонтальной прокрутки нет ни на 390, ни на 768, ни на 1440, ни на 1920 px.
- Все 51 анимируемых блока раскрываются при прокрутке — и при медленной, и при быстрой;
  при `prefers-reduced-motion` видны сразу.
- Все `<img>` имеют `alt`; у всех полей формы есть `<label>`.
- Контраст: основной текст 17.2:1, вторичный 6.9:1 (норма WCAG AA — от 4.5:1).
- Минимальный размер текста — 11 px.
- Вес страницы: около 1.9 МБ, из них 1.2 МБ — фотографии и 0.5 МБ — шрифты.
- Работают: табы форматов (мышь + стрелки клавиатуры), полноэкранное мобильное меню
  (крестик, Escape, блокировка прокрутки страницы), клик-загрузка видео,
  форма → WhatsApp с готовым текстом.
- Вёрстка соответствует чек-листу навыка `high-end-visual-design`: 18 пунктов из 18.

Служебные скрипты проверки лежат в `tools/` (`audit`, `interact`, `geometry`, `validate`,
`final-check`, `conversion-check`, `pixels`, `optimize`, `skill-check`, `menu-check`, `shoot`).
Запускаются через `node tools/<имя>.mjs` при включённом `npm run serve`.
